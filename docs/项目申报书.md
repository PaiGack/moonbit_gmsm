## 项目简介

Moon_gmsm 把 Go 生态里成熟的国密算法库 tjfoc/gmsm（Apache-2.0）按 GM/T 0003-2012、GM/T 0004-2012、GM/T 0002-2012 三个标准重新实现到 MoonBit 上，使需要国密合规的 MoonBit 库和应用不再依赖 Go 或 C 运行时即可完成签名、杂凑与对称加解密。

## 核心功能范围

### SM2

- 提供 P-256 推荐曲线参数（p / a / b / n / Gx / Gy）与 256 位大数运算工具，对应 `sm2p256` 的底层域运算；
- 提供 `GenerateKey`、`PublicKey` / `PrivateKey` 密钥对类型，以及私钥推导公钥、点是否在曲线上的判断，对应 `GenerateKey` 与 `(*PrivateKey).Public`；
- 提供 SM2 数字签名 `Sm2Sign` / `Sm2Verify`（含 Z 值预处理 entl ‖ uid ‖ a ‖ b ‖ Gx ‖ Gy ‖ x ‖ y 与 SM3 摘要 `ZA(pub, uid)`）以及 ASN.1 签名格式转换 `SignDigitToSignData` / `SignDataToSignDigit`；
- 提供 SM2 加解密 `Encrypt` / `Decrypt`，支持 C1C3C2 与 C1C2C3 两种密文排布，对应 `CipherMarshal` / `CipherUnmarshal`；
- 提供密钥协商 `KeyExchangeA` / `KeyExchangeB`，用于双方基于 SM2 派生共享密钥；
- 提供公钥压缩 / 解压 `Compress` / `Decompress`，与 04 / 02 / 03 形式的字节相互转换。

### SM3

- 实现 GM/T 0004-2012 压缩函数与消息填充；
- 提供 `SM3` 流式状态（`new / write / sum / reset / size`），输出 32 字节摘要，与 Go `hash.Hash` 接口行为对齐；
- 提供一次性摘要 `Sm3Sum(data)` 与多段拼接版本 `Sm3SumMulti`。

### SM4

- 实现 SM4 轮函数与密钥扩展，对应 `generateSubKeys`；
- 提供块加密接口 `NewCipher(key)`，对齐 Go `cipher.Block` 的 `BlockSize` / `Encrypt` / `Decrypt`；
- 提供分组模式封装 `Sm4Ecb` / `Sm4Cbc` / `Sm4Cfb` / `Sm4Ofb`，附带 PKCS7 填充与 `SetIV(iv)` 默认向量设置；
- 提供 SM4-GCM `Sm4Gcm`，对应 `Sm4GCM` / `GCMEncrypt` / `GCMDecrypt`，输出密文与认证标签。

### 测试与工程

- 使用 GB/T 32918、GB/T 32905、GB/T 32907 标准向量编写回归测试；
- 接入 GitHub Actions CI，覆盖 `moon check` / `moon test` / `moon build`；
- 提供 README 示例，覆盖 SM2/SM3/SM4 算法。

## 移植或参考说明
- 原项目名称：tjfoc/gmsm
- 原项目链接：https://github.com/tjfoc/gmsm
- 原项目许可证：Apache License 2.0
- 本项目许可证：Apache License 2.0（与原项目一致，符合许可证要求）

与原项目相比，本项目做了以下简化与重新设计：

- 用 MoonBit 原生的包结构、`struct` / `enum` / 块注释组织代码，把 Go 的 `big.Int` 改成 4 × UInt64（256 位）定长大数 `Bn`，没有外部闭源依赖；
- 用 MoonBit 的 `moon test` 黑盒 / 白盒测试取代 Go 的 `_test.go`，白盒测试集中在 `*_wbtest.mbt`；
- 不依赖 Go 的 `crypto` 标准库、`crypto/tls`、错误接口与切片语义，目标是在 MoonBit WASM / Native 多后端独立运行；
