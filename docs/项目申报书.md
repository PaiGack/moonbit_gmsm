## 项目简介
Moon_gmsm 把 Go 生态里成熟的国密算法库 tjfoc/gmsm（Apache-2.0）按 GM/T 0003-2012、GM/T 0004-2012、GM/T 0002-2012 三个标准重新实现到 MoonBit 上，覆盖 SM2 椭圆曲线公钥密码、SM3 密码杂凑、SM4 分组密码三类商用密码算法。项目仓库已建立 sm2/、sm3/ 两个子包与 gmsm 顶层聚合包，给出 P-256 推荐曲线参数、SM3 压缩函数与流式接口、SM2 sign/verify/encrypt/decrypt 的函数签名；当前提交里 SM3 已通过标准向量测试，SM2 仍是大数运算与点运算的骨架版本（`derive_public_key`、`sm2_verify` 等仍是占位实现），SM4 尚未动工。后续在 MoonBit 多后端（WASM / Native）上把这些补齐，使需要国密合规的 MoonBit 库和应用不再依赖 Go 或 C 运行时即可完成签名、杂凑与对称加解密。

## 核心功能范围
- 提供 P-256 推荐曲线参数（p / a / b / n / Gx / Gy）与 256 位大数（8 × UInt32）运算工具，作为 SM2 点运算的基础；
- 提供 SM2 密钥生成、私钥推导公钥、点是否在曲线上的判断接口；
- 提供 SM2 数字签名 `sm2_sign / sm2_verify`，含 Z 值预处理（entl ‖ uid ‖ a ‖ b ‖ Gx ‖ Gy ‖ x ‖ y）与 SM3 摘要；
- 提供 SM2 加解密 `sm2_encrypt / sm2_decrypt`，支持 C1C3C2 与 C1C2C3 两种密文排布；
- 提供 SM3 密码杂凑 `sm3_sum / sm3_sum_multi` 与可复用的 `SM3` 流式状态（`new / write / sum`），输出 32 字节；
- 提供 `gmsm` 顶层包，对外重新导出 SM2/SM3 的类型与函数，便于 `paigack/gmsm` 单一依赖入口；
- 使用 GB/T 32918、GB/T 32905 标准向量编写回归测试，`sm3` 已通过；
- 接入 GitHub Actions CI（`.github/workflows/ci.yml`），覆盖 `moon check` / `moon test` / `moon build`；
- 准备后续实现 SM4 轮函数、密钥扩展、ECB/CBC 模式与 PKCS7 填充，与 SM2/SM3 一起组成完整国密套件。

## 移植或参考说明
- 原项目名称：tjfoc/gmsm
- 原项目链接：https://github.com/tjfoc/gmsm
- 原项目许可证：Apache License 2.0
- 本项目许可证：Apache License 2.0（与原项目一致，符合许可证要求）

与原项目相比，本项目做了以下简化与重新设计：

- 用 MoonBit 原生的包结构、`struct` / `enum` / 块注释组织代码，把 Go 的 `big.Int` 改成 8 × UInt32 定长大数，没有外部闭源依赖；
- 用 MoonBit 的 `moon test` 黑盒 / 白盒测试取代 Go 的 `_test.go`，白盒测试集中在 `*_wbtest.mbt`；
- 当前实现范围只覆盖 SM2 / SM3 的算法核心，省略上游的 `gmtls`、`x509` 证书链、`pkcs12` 等首期不涉及的模块，留作后续扩展；
- 不依赖 Go 的 `crypto` 标准库、x509 解析、错误接口与切片语义，目标是在 MoonBit WASM / Native 多后端独立运行；
